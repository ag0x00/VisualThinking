## Key meta-findings across all four phases

1. **The "central theoretical pillar" framing was a load-bearing overclaim.** Three unifications were retired: Galanter ↔ Berlyne, Russell circumplex universality, Helmholtz-Gibson-Bayesian consensus. The original sweeps presented all three as canonical; none of the three is consensus in the current literature.

2. **Base rate of canonicity overclaim was high.** Of the 4 Phase 3 audit anchors, 3 needed major or moderate revision. 75% overclaim rate. High enough to justify making the audit a default convention, not an exception.

3. **Discovery via training-data recall is systematically biased toward training-era popularity.** The Phase 2 tools sweep missed Strudel (which exploded since 2023), Transformers.js (2024+), the modern WGSL DX stack (2024+). Anything dated 2023+ was at high risk of being missed without explicit npm-search + awesome-list audit.

4. **Primary sources matter more than expected.** Two PDFs (Hertzmann, Cramer) substantially changed the wiki's positioning when read in full. Cramer especially: the secondary summaries captured only the glitch-aesthetics strand, missing four other substantive arguments (anti-universal-machine, DIY-vs-corporate, semiotic-shift-to-indexical, systems-crisis self-critique).

5. **Cross-cultural variation is the most-reliable falsifier in perception-psychology.** Every Phase 3 anchor with cross-cultural data showed substantial variation. WEIRD-only validation should be a default flag.

6. **The "universal substrate + cultural overlay" pattern recurs.** Color symbolism, face emotion, valence-arousal geometry, perceptual constancies — all show some universal substrate with culturally-variable categorical overlay. The wiki's *operational* recommendation, stable since the Affect Foundations sweep, is *prefer dimensional / structural specifications over categorical universal claims*. Phase 3 reinforces this.

7. **Successor theories matter as much as current theories.** The wiki had pages for processing fluency, neuroaesthetics, predictive-processing — but presented them as Berlyne's *continuation*, not its *replacement*. Distinguishing "historical infrastructure" from "live contemporary framework" required explicit attention.

## What this means for future sweeps

The remaining sweeps (Practical Design, Movement-Rhythm-Style-Symbolism, Body Language Depth, Implementation-notes pass) execute under the post-Option-C methodology. Specifically:

- **Practical Design sweep** (next): typography + negative space + light vocabulary + materials. Conventions 1, 2, 5, 6 apply. The typography literature is mature and pre-2010-anchored (Bringhurst, Müller-Brockmann); explicit successor-theory check needed (e.g., variable fonts changed type design; OKLCH-aware color systems changed legibility analysis). The light vocabulary literature is film/photo-tradition (Pixar, ASC); cross-cultural validity check needed for warmth/coolness/depth conventions.
- **Movement-Rhythm-Style-Symbolism**: heavily theoretical (Eisenstein, Wölfflin, Panofsky). All six conventions apply — these are exactly the canonical-figure-anchored fields most prone to overclaim. Expect substantial framing-canonicity work.
- **Body Language Depth**: the smallest sweep. Conventions 4, 5 apply (primary sources from de Gelder, Birdwhistell; explicit cultural validity for pose semantics).
- **Implementation-notes pass**: after Practical Design. Conventions 3 (tools sweeps must audit) apply.

## Closing note

The Option C plan was the user's response to two errors made on 2026-05-17 morning: the tools-sweep training-data-recall failure, and the Galanter canonicity overclaim. Both errors were caught by user audit, not by methodology. Phase 4 closes the gap: the same failure modes are now caught by *convention* before publication, not by user audit afterward.

Future canonicity overclaims (when they happen — they will) are now caught faster because:

- Catalog-stub cross-check + framing-canonicity audit are explicit pre-publication checks
- npm + GitHub + awesome-list scan is explicit for tools sweeps
- WebFetch failures don't silently degrade to secondary sources
- Cross-cultural validity is a default flag, not an afterthought
- Successor theories are tracked alongside historical anchors
- Unification language is a red flag that triggers audit

These conventions aren't a guarantee against future overclaim — but they shift the work of catching it from user-audit-after to convention-driven-before. Which is the right shift.
