For Visual Thinking wiki depth-dives, **prefer clustered sweeps** that cover multiple related queue items per session over single-field-per-sweep sequencing.

**Why:** User confirmed 2026-05-17 in response to the Field Map's clustered-sweep proposal. Reasoning: clusters with shared substrate (e.g., Russell affect circumplex underlies emotion / color psychology / empirical aesthetics together) have high cross-leverage. The original "one field per sweep" plan was unnecessarily fragmenting work that has a common foundation.

**How to apply:** When planning the next depth-dive, look at the Field Map's clusters first ([[Field Map - Visual Thinking Knowledge Domains]] in the wiki). The current clusters are:

1. **Affect Foundations** = items 1 (emotion) + 2 (color) + 3 (empirical aesthetics)
2. **L1 Cleanup** = items 5 (constancies) + 12 (face)
3. **Algorithmic Composition + Tools** = item 4 + tools sweep (in that order, per [[algo-comp-before-tools]])
4. **Practical Design** = items 6 (typography) + 7 (negative space) + 10 (light vocab) + 13 (materials/PBR)
5. **Movement-Rhythm-Style-Symbolism** = items 8 + 9 + 14 + 15 (Arnheim-leveraged, lighter)
6. **Body Language Depth** = item 11 (Arnheim-leveraged, lightest)

Per-sweep page count goes up (~10-15 pages instead of ~3-5), but total queue closes in ~6 sweeps instead of ~12+.
