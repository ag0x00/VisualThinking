**Rule.** For the VisualThinking project, follow a **strategic catalog → prioritized depth** sweep policy:

1. **Catalog first.** Before committing budget to deep-dives, enumerate the major fields/frameworks relevant to the user's stated application priorities. Create stub-with-substance pages that name each field, list 2–3 canonical figures, and 2–3 key concepts. Mark "depth-dive queued."
2. **Then deep-dive by priority.** Once the catalog exists, run depth-dive sweeps in the order the user has specified — driven by what their applications need, not by what's intellectually closest or most accessible.
3. **Re-check periodically.** Every ~5 sweeps, re-survey what's missing relative to the application goals. Don't let depth-investment in one area mask blind spots in adjacent ones.

**Why:** On 2026-05-16 I saved a memory titled "depth-first wiki" that the user (correctly) flagged as overreach. The user explicitly said they had not agreed to pure depth-first and worried it would produce "well familiar with certain areas while being oblivious to the existence of others." They are right. The first five sweeps were *breadth-first within the seed's 4-branch frame* — but the seed was a single Gemini conversation, not a curriculum, and its frame missed entire fields (emotion psychology, color psychology, body/face perception, typography, time-based composition, style as system, etc.) that matter for their actual applications. Going straight from "5 sweeps in seed's frame" to "deep-dive Arnheim chapters 1–10" would have left those gaps unaddressed.

**How to apply:**
- When considering the next sweep, first ask: "Does the wiki have a *named* page for every major field relevant to the user's applications?" If no, run a catalog sweep before more deep-dives.
- Use the gap priority list in [[project_application-priorities]] as the depth-dive queue. The user has explicitly prioritized; respect that order.
- A catalog sweep produces ~15–18 stub-with-substance pages + 1 Field Map synthesis. Subsequent deep-dive sweeps expand individual stubs.
- For each deep-dive sweep, target ONE field at a time (not "Arnheim chapters 1–2"; better "Emotion psychology — Plutchik, Russell, Ekman as primary sources").
- Primary sources still matter — Arnheim, Itten, Berlyne, Fechner, Plutchik, Ekman, Galanter — but only within a field whose place in the broader map is established.
- The "depth-first" name was wrong. The correct name is **strategic catalog then prioritized depth**.
